# Угадай слово

Игра на ассоциации в духе [guess-word.com](https://guess-word.com/) и Contexto.
Загадано слово, попытки не ограничены. После каждого слова игра показывает,
на каком месте оно стоит в рейтинге близости к загаданному. Само загаданное
слово стоит на 1-м месте.

- 🟩 до 100-го места — очень горячо, 🟨 до 1000-го — тепло, 🟥 дальше — холодно
- три уровня сложности (🐥 / 🦊 / 🦉), новые слова каждый день в 18:00 по Москве
- архив прошлых уровней, подсказки, кнопка «сдаться», список 500 ближайших слов
- своё слово: загадай и отправь ссылку друзьям
- статистика и серия побед, прогресс сохраняется в браузере
- 👁 скрывает слова (удобно на стриме)

## Как это работает

Близость слов считается в браузере по сумме двух моделей:

- [RusVectores](https://rusvectores.org/) `ruwikiruscorpora_upos_cbow_300_10_2021`
  (НКРЯ + Википедия): хорошо знает смысл слов, имена собственные размечены отдельно;
- [fastText](https://fasttext.cc/docs/en/crawl-vectors.html) `cc.ru.300` (Common Crawl):
  учитывает части слов, поэтому «коровка» близка к «корове», а «котёнок» к «коту».

Вместе они лучше, чем по отдельности: на наборе RUSSE HJ корреляция с оценками людей
0,743 против 0,707 и 0,697. Векторы центрируются, иначе частые слова оказывались бы
далеко от редких просто из-за частотности. Сервер не нужен: это статический сайт,
его можно выложить на GitHub Pages, Netlify и куда угодно ещё.

В `data/` лежат ~27 тыс. самых частотных существительных в начальной форме и их векторы
в сжатом виде (product quantization, 200 байт на слово). Место слова считается среди
15 тыс. самых частых: иначе верх рейтинга занимают слова, которые никто не вводит
(«листоед», «капустница»). Вводить можно и более редкие слова.

| Файл | Что внутри |
| --- | --- |
| `index.html`, `css/`, `js/app.js` | интерфейс |
| `js/engine.js` | загрузка словаря и подсчёт рейтинга |
| `js/levels.js` | слова для ежедневных уровней |
| `tools/build_data.py` | сборка `data/` из моделей RusVectores и fastText |

## Запуск локально

Нужен любой статический сервер (из-за ES-модулей `file://` не подойдёт):

```sh
python3 -m http.server 8000
# открыть http://localhost:8000
```

## Публикация

В репозитории есть workflow `.github/workflows/pages.yml`: после пуша в `main`
сайт выкладывается на GitHub Pages. Включить: **Settings → Pages → Source: GitHub Actions**.

## Пересборка словаря

```sh
pip install numpy pymorphy3 pymorphy3-dicts-ru
curl -LO http://vectors.nlpl.eu/repository/20/220.zip && unzip 220.zip model.txt
curl -LO https://dl.fbaipublicfiles.com/fasttext/vectors-crawl/cc.ru.300.vec.gz
python tools/build_data.py model.txt cc.ru.300.vec.gz
```

Слова для уровней правятся в `js/levels.js`. Каждое должно быть в `data/words.txt`.
Порядок слов по дням зависит от всего списка, поэтому правка меняет слова и у прошедших уровней.
